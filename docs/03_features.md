## 機能要件

### ユーザーストーリー形式

#### 認証
- [ ] P0 ユーザーはメールとパスワードを設定せずに利用できる

#### 本棚共有機能
- [ ] P0 読んだ本を登録し終えたユーザーはURLを共有することで自分の本棚を相手に見せる（共有する）ことができる

#### 本の管理
- [x] P1 ユーザーは登録済みの本（タイトル・作者・カテゴリ・Amazon URL・表紙・読了）を後から編集できる
- [x] P1 本棚を見た人は、読了した本と積読（未読）の本を見分けられる
- [x] P1 ユーザーはプリセット（カテゴリ順・作者順）で本をまとめて並べ替えられる
  - カテゴリ順は「カテゴリ → 作者」、作者順は「作者 → カテゴリ」の順に並べる（キーが同じ本は今の並びを保つ）
  - 並べたキーが主キーになり、主キーの仕切りが大きく、サブキーの仕切りが小さくなる（画面・共有URL・OGP画像で共通）
  - 本を追加すると、主キーが同じ本の最後尾に入る
- [x] P1 ユーザーは仕切りをまとめて表示・非表示にできる（画面・共有URL・OGP画像で共通）
- [x] P1 ユーザーは全冊の並べ方（背表紙・面出し）をまとめて切り替えられる
  - TODO: 漢字のカテゴリ名・作者名は読みではなく文字コード順になる（読みのデータがないため）

#### 共有
- [x] P1 共有URLを Slack / SNS に貼ると、本棚の名前・冊数・表紙が並んだプレビュー画像（OGP）が表示される

※ 優先度：P0=MVP必須 / P1=あると良い / P2=将来対応
